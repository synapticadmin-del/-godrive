- Reviewed the console as an operator's workplace at base commit `697f4347045e67bc488a9c91631d6497ab6511d7`:

  trip/user tables silently truncate to 200 rows behind a search box that filters only those 200 — the
  console answers "no matching trips" for trips that exist, while `AuditLogPage.tsx:215-219` shows the
  codebase already knows how to disclose a cap.
