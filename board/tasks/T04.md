## Questions you must answer

1. Webhook security: HMAC-SHA512 is claimed — verify the computation matches Paymob's documented concatenation order exactly, that comparison is constant-time, and that the raw body (not a re-serialised object) is hashed.
2. Webhook idempotency: Paymob retries. Can the same successful payment credit a wallet twice? What is the dedupe key and where is it stored?
3. Webhook authenticity beyond HMAC: is there IP allow-listing, and does the handler verify the amount and currency against the stored intention rather than trusting the callback body?
4. Stub mode: when `PAYMOB_API_KEY` is absent the code runs as a stub. Can stub mode be reached in production? Does it credit real wallets?
5. Intention lifecycle: creation, expiry, abandonment, and cleanup. Can an intention be paid after the trip it was for has ended or been cancelled?
6. Failure and reconciliation: what happens when the webhook never arrives? Is there a polling fallback against Paymob's transaction-inquiry API? Without one, users lose money silently.
7. 3-D Secure / OTP-in-flow: how is the redirect handled in a Flutter WebView, and what happens if the user kills the app mid-flow?
8. Payment method coverage for Egypt: card, Fawry, Vodafone/Etisalat/Orange Cash, Meeza, InstaPay, and cash. Which exist, which are stubs, which are absent entirely?
9. Captain payouts — this appears to be entirely missing. There is no `routes/payouts.ts`. Specify the whole pipeline: payout eligibility, schedule, minimum threshold, bank/wallet destination collection and verification, batch file generation, PSP disbursement API, failure handling, and the ledger entries for each state.
10. Chargebacks and disputes: is there any representation of a reversal? What happens to a captain who has already been paid for a trip whose payment is later reversed?
11. PCI scope: does any card data touch the Worker, the Flutter app, or the logs? Confirm the integration keeps the app out of scope.

and the price-negotiation model of inDrive, hardened to full production quality.
