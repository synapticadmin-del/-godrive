## Questions you must answer

1. Produce the current consolidated schema: every table, its columns, types, nullability, defaults, and its relationships. This artefact does not exist and the team needs it.
2. Foreign keys: are they declared, and are they enforced (SQLite requires `PRAGMA foreign_keys=ON`, and D1's behaviour must be verified rather than assumed)? List every orphan-row risk.
3. Indexes: for each frequent query path (nearby captains, trips by captain+status, wallet transactions by user, audit log by date, documents by status), does a covering index exist? 0019 added one — what else is missing? Identify full-table scans.
4. Money columns: after 0005, is every currency column an integer? Any remaining REAL/FLOAT? Any column storing money as TEXT?
5. Timestamps: consistent type and timezone across tables? Unix seconds vs milliseconds vs ISO strings mixed in the same schema is a common source of silent bugs — check.
6. Enum discipline: statuses stored as free text (`trip.status`, document status, payment status) — is there a CHECK constraint or is any string accepted? Enumerate the actual value sets used in code.
7. Denormalisation: which columns duplicate data that lives elsewhere (fare on trip vs ledger, captain name on trip, balance on user), and what keeps them in sync?
8. Migration safety: are the migrations idempotent and forward-only? Any that would fail on a non-empty production table? Any destructive statement? Is there a rollback story at all?
9. 0017 is a data fix (`fix_document_type_titles`) — how many other migrations mutate data rather than schema, and is that tracked?
10. Retention and growth: `trip_path_points` grows without bound (sampling every 30 s). Same for `audit_log`, `otp_attempts`, `turnstile_verifications`, `refresh_tokens`. What does `lib/cleanup.ts` actually delete, on what schedule, and what is the projected D1 row count and storage at 1,000 trips/day over 12 months?
11. D1 limits: database size cap, query duration, and the number of subrequests a Worker can make. Where does the current design approach a limit?
12. Backup and restore: is there any? What is the RPO/RTO today, honestly?
