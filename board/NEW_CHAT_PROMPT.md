# NEW_CHAT_PROMPT — انسخ ده في كل شات جديد

هذا الملف يحتوي على البرومبت الجاهز. انسخه كما هو — بدون تعديل — في أي شات جديد.
نفس النص بالظبط في كل مرة. البروتوكول هو اللي بيمنع التكرار، مش إنك تكتب حاجة مختلفة.

---

## البرومبت الأساسي (استخدم ده دايمًا)

```
مراجعة موزّعة لمشروع Synaptic Go — نفّذ مهمة واحدة لوحدك من الأول للآخر.

Repo: synapticadmin-del/-godrive
Board branch: review-board
اقرأ board/PROTOCOL.md من برانش review-board ونفّذه حرفيًا.

الترتيب الإلزامي:
1. ولّد CHAT_ID خاص بيك.
2. احجز أول مهمة غير محجوزة (atomic claim على board/claims/TNN.md) — قبل ما تقرأ
   أي سطر كود. فيه شاتات تانية بتفتح في نفس الثواني، والحجز هو اللي بيمنع التكرار.
3. أكّد الحجز بإعادة قراءة الملف والتأكد إن claimed_by = الـ CHAT_ID بتاعك.
4. اقرأ board/tasks/TNN.md — ده البريف بتاعك.
5. نفّذ المراجعة العميقة بنفسك. تقدر تفرد ساب إيجنتس على راحتك.
6. اكتب المستند حسب board/TEMPLATE.md، ارفعه على برانش جديد، وافتح PR على main.
7. حدّث ملف الحجز: status: done + لينك الـ PR.

ممنوع: push على main · merge أو close لأي PR · تعديل ملف مش بتاعك ·
تعديل .github/workflows · تغيير كود المنتج (المرحلة دي مراجعة وخطة بس) ·
تسألني أي سؤال قبل ما تبدأ أو أثناء الشغل.

في الآخر رجّعلي سطرين بس: رقم المهمة + لينك الـ PR.
```

## النسخة المثبّتة على مهمة معيّنة

استخدمها لو عايز تتحكم إن الشات ده يشتغل على مهمة بالذات بدل ما ياخد أول واحدة فاضية.
غيّر `T07` بس.

```
مراجعة موزّعة لمشروع Synaptic Go — نفّذ المهمة T07 لوحدك من الأول للآخر.

Repo: synapticadmin-del/-godrive
Board branch: review-board
اقرأ board/PROTOCOL.md من برانش review-board ونفّذه حرفيًا، بفرق واحد:
المهمة محدّدة سلفًا = T07. احجزها بنفس آلية القفل الذرّي.
لو لقيتها محجوزة من شات تاني (claimed_by مش الـ CHAT_ID بتاعك) — قف فورًا
وقول لي كده، ما تاخدش مهمة تانية بدالها.

بعد الحجز: اقرأ board/tasks/T07.md، نفّذ المراجعة، اكتب المستند حسب
board/TEMPLATE.md، افتح PR على main، وحدّث ملف الحجز بـ status: done ولينك الـ PR.

ممنوع: push على main · merge لأي PR · تعديل ملف مش بتاعك ·
تعديل .github/workflows · تغيير كود المنتج · تسألني أي سؤال.

رجّعلي سطرين: رقم المهمة + لينك الـ PR.
```

## لو عايز شات يشتغل مهمتين ورا بعض

نادرًا ما تحتاج ده — شات لكل مهمة أنضف وأسرع. لكن لو حبيت:

```
… (نفس البرومبت الأساسي) …
بعد ما تخلص المهمة وتقفل الحجز بتاعها، ارجع للخطوة 2 واحجز المهمة اللي بعدها،
وكرّر لحد ما تخلص مهمتين. رجّعلي سطرين لكل مهمة.
```

## متابعة الحالة

من أي شات — أو من GitHub مباشرة — اعرض محتوى `board/claims/` على برانش
`review-board`. كل ملف = مهمة محجوزة أو خالصة، وجواه `status` و`pr`.

للسؤال السريع "إيه اللي فاضل؟" استخدم برومبت:

```
Repo: synapticadmin-del/-godrive · branch review-board
اعرض لي محتوى board/claims/ وقول لي: المهام الخالصة (بلينكات الـ PR)،
المهام اللي قيد التنفيذ (ومن إمتى)، والمهام اللي لسه محدش خدها من T01 لـ T26.
ما تحجزش حاجة وما تنفّذش أي مهمة — تقرير بس.
```
