## What I actually did

1. **Split the cron.** `cron/{cleanup,dispatch,invoices}.ts` + `cron/scheduled.ts` (dispatcher) +
   `cron/types.ts`. Job bodies moved verbatim — all 7 SQL statements byte-identical, checked
   mechanically. The dispatcher switches on `event.cron`, so the monthly invoice job stops running
   on the every-minute trigger (1,440×/day on the 1st → once), and collects per-job failures and
   rethrows, so a throwing job fails the invocation instead of being swallowed while Cloudflare
   records success. One job's failure still cannot skip its siblings.
2. **`lib/health.ts`** extracted. Same 200, same fields, but **async and status-carrying** so E12
   can make `/health` answer 503 on a broken binding without reopening the frozen file.

   and `walletRoutes` are both mounted at `"/"` with `use("*", authMiddleware)`, so a root `*`
   swallows every unmatched path before `notFound()`. Found by asserting the status code, not by
   reading. Both prefixes are now terminated explicitly ahead of the `"/"` mounts.
4. **Public mounts late-bind.** `publicUserRoutes` (E16, PR #92 unmerged) and `publicSafetyRoutes`
   (E13, not started) do not exist on `main`; a static import fails `tsc`, and copying the handlers
   would fork the payload E13 must redact into a file nobody can edit again. Both mounts probe the
   export at request time and fall through to today's behaviour until it appears — so they activate
   on merge with **no edit to the frozen file**. Contract published on the PR; E16's PR already matches.
5. **Verified, not asserted.** Rebuilt the toolchain in-sandbox (npm tarballs firewalled; types and
   runtime came from jsdelivr), compiled and booted the Worker: `tsc --noEmit` exit 0 (baseline on
