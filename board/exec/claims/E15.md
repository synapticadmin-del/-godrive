## What I actually did

1. **`lib/routing.ts` — the fallback is no longer mandatory, silent, or a price.** Deleted
   `DEFAULT_OSRM` and made `osrmBaseUrl` a **required argument** on both exported functions, so
   nothing can silently inherit a public endpoint. Added `allowFallback`, **defaulting to `true` =
   today's exact behaviour**, which is what makes this safe to merge beside E09's untouched call
   sites; `false` raises `ROUTE_UNAVAILABLE`. Every degradation funnels through one function and
   emits a `route_fallback` counter via E12's `lib/log.ts` (§5.4's single sink) — the metric item 11
   never had. The public host is now *detected*: still called on the estimate path (refusing there
   would make every estimate a straight line — worse than the bug), refused outright on a price.
2. **`wrangler.toml` — all three environments off `router.project-osrm.org`.** Structural diff is
   127 live lines before and after with only the three `OSRM_URL` values changed.

   Additive, forward-only, nullable on purpose (NULL means "not recorded", which is a different
   fault from "E09 failed to write it"). Rollback stated in the header and the PR.
4. **`lib/geocode.ts` + `routes/geocode.ts` — viewbox bias.** `/search` now takes the optional
   `lat`/`lng` pair `/reverse` already uses and biases to ~100 km around it. `bounded=1` deliberately
