# فيتشرز تطبيق العميل (Rider)

> **النطاق:** تطبيق Flutter للعميل — `apps/rider/`
> **المصدر:** قراءة مباشرة من الكود (API routes + بنية الشاشات)
> **آخر تحديث:** 2026-08-01

---

## 1. المصادقة والتسجيل

| الفيتشر | الوصف | المصدر |
|---------|-------|--------|
| تسجيل دخول OTP | رمز 6 أرقام عبر واتساب (للرقم المصري) أو إيميل | `auth.ts` |
| Turnstile anti-bot | تحقق Cloudflare Turnstile إجباري قبل إرسال OTP | `auth.ts` + `turnstile.ts` |
| تسجيل بالإيميل + كلمة مرور | بديل للـ OTP — PBKDF2 salted hash | `auth.ts` `/register` |
| Refresh token rotation | جلسة 30 يوم مع تدوير تلقائي وإبطال القديم | `auth.ts` `/refresh` |
| Hard logout | تسجيل الخروج يبطل كل refresh tokens المستخدم | `auth.ts` `/logout` |
| حساب معلّق | رسالة واضحة عند تعليق الحساب (`SUSPENDED`) | `auth.ts` |

## 2. طلب الرحلة

| الفيتشر | الوصف | المصدر |
|---------|-------|--------|
| تقدير الأجرة | حساب فوري للأجرة قبل التأكيد (OSRM routing) | `trips.ts` `/estimate` |
| عرض الكباتن القريبين | سيارات متحركة على الخريطة (probe بدون إنشاء رحلة) | `trips.ts` `/estimate` |
| اختيار نوع المركبة | فئات اقتصادية/مريحة/كبيرة بمضاعفات سعر مختلفة | `vehicle_types` + `createTripSchema` |
| طريق متعدد النقاط | حتى 5 نقاط توقف (waypoints) | `createTripSchema` |
| رحلة مجدولة | حجز مسبق لوقت لاحق — يُفعَّل تلقائيًا بالكورن | `trips.ts` + `index.ts` cron |
| عرض سعر مخصص | العميل يقترح أجرته (`offeredPrice`) | `createTripSchema` |
| بروموكود | خصم نسبة أو مبلغ ثابت مع تحقق فوري | `promo.ts` |
| طرق دفع متعددة | كاش / محفظة / بطاقة (Paymob) | `createTripSchema` + `payments.ts` |
| رحلة شركة B2B | ربط تلقائي بالشركة إذا العميل موظف مسجل | `companies.ts` |

## 3. المزايدة والتفاوض

| الفيتشر | الوصف | المصدر |
|---------|-------|--------|
| عرض عروض الكباتن | قائمة مباشرة بعروض الأسعار المضادة | `trips.ts` `GET /:id/bids` |
| ETA حقيقي لكل كابتن | وقت وصول محسوب من موقع الكابتن الفعلي (OSRM) | `trips.ts` `attachCaptainEtas` |
| بيانات الكابتن الكاملة | صورة، تقييم، عدد رحلات، مركبة، لون، لوحة | `trips.ts` + `captain.ts` |
| قبول عرض | اختيار كابتن معين → تعيين فوري + إشعار | `trips.ts` `POST /:id/accept-bid` |
| تحديث لحظي للعروض | broadcast عبر WebSocket لأي عرض جديد | `trips.ts` + `TripRoom` |

## 4. تتبع الرحلة اللحظي

| الفيتشر | الوصف | المصدر |
|---------|-------|--------|
| WebSocket حي | قناة مباشرة للرحلة (TripRoom Durable Object) | `index.ts` `/ws/trips/:id` |
| تحديث موقع الكابتن | إحداثيات كل 30 ثانية مع heading | `captain.ts` `/location` |
| مسار الرحلة | تسجيل نقاط الطريق (path points) كل 30 ثانية | `captain.ts` + `trips.ts` `/path` |
| حالة الرحلة المباشرة | assigned → arrived → in_progress → completed | `trips.ts` |
| بيانات الكابتن المُعيَّن | اسم، صورة، مركبة، تقييم، عدد رحلات | `trips.ts` `withCaptain` |
| مشاركة التتبع | رابط عام بدون تسجيل دخول (trip share token) | `safety.ts` `/share` |
| إشعارات Push | قبول، وصول، بدء، إنهاء، إلغاء — عبر FCM | `notifications.ts` |

## 5. الدفع والمحفظة

| الفيتشر | الوصف | المصدر |
|---------|-------|--------|
| محفظة داخلية | رصيد ج.م مع سجل معاملات كامل | `wallet.ts` |
| شحن المحفظة | Paymob iframe (بطاقة/محفظة إلكترونية) | `payments.ts` |
| خصم تلقائي | عند إتمام الرحلة من المحفظة مع idempotency | `trips.ts` `/complete` |
| دفع كاش | تحصيل يدوي من الكابتن — بدون خصم من العميل | `trips.ts` |
| فشل الدفع | rollback تلقائي إذا رصيد غير كافٍ | `trips.ts` |
| سجل المعاملات | آخر 50 معاملة مع pagination | `wallet.ts` |
