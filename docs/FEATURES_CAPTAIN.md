# فيتشرز تطبيق الكابتن (Captain)

> **النطاق:** تطبيق Flutter للكابتن — `apps/captain/`
> **المصدر:** قراءة مباشرة من الكود (API routes + بنية الشاشات)
> **آخر تحديث:** 2026-08-01

---

## 1. التسجيل والـ Onboarding

| الفيتشر | الوصف | المصدر |
|---------|-------|--------|
| تسجيل OTP | نفس آلية العميل — واتساب أو إيميل | `auth.ts` |
| ملف كابتن | إنشاء/تحديث بيانات المركبة والرخصة | `captain.ts` `/profile` |
| الاسم الرباعي | first/father/grandfather/family — إلزامي مصري | `captainProfileSchema` |
| الرقم القومي | 14 رقم مع تخزين مشفر (migration 0012) | `captainProfileSchema` |
| تاريخ الميلاد | + تاريخ انتهاء الرخصة + سنة المركبة | `captainProfileSchema` |
| حالة الموافقة | pending → approved → suspended | `captains.approval_status` |

## 2. المستندات والتحقق

| الفيتشر | الوصف | المصدر |
|---------|-------|--------|
| رفع مستندات | صور/PDF حتى 10MB مع sniffing للبايتات | `captain.ts` `/upload` |
| أنواع مستندات ديناميكية | الإدارة تضيف/تعدل بدون نشر تطبيق | `document_types` catalog |
| مستندات إلزامية/اختيارية | يحددها الأدمن — تظهر badge في التطبيق | `document_types.required` |
| إعادة رفع | استبدال تلقائي للمستند المرفوض/المعلق | `captain.ts` `/documents` |
| حذف مستند معلق | "×" يحذف الـ pending فقط | `captain.ts` `DELETE /documents/:type` |
| عرض المستندات | سجل كامل بالحالة والسبب عند الرفض | `captain.ts` `GET /documents` |
| IDOR protection | الكابتن يرى ملفاته فقط — لا يصل لمجلد غيره | `captain.ts` `/file/*` |

## 4. استقبال العروض والرحلات

| الفيتشر | الوصف | المصدر |
|---------|-------|--------|
| Inbox مباشر | WebSocket شخصي لكل كابتن (CaptainInbox DO) | `CaptainInbox.ts` |

| تصفية بالمدينة | لا يرى رحلات مدن أخرى | `captain.ts` + `trips.ts` |
| قائمة الرحلات القريبة | `/nearby-requests` مع المسافة الفعلية | `captain.ts` |
| بيانات الراكب | اسم، صورة (DiceBear fallback)، تقييم | `captain.ts` |

## 5. قبول الرحلة والتنفيذ

| الفيتشر | الوصف | المصدر |
|---------|-------|--------|
| قبول مباشر | تعيين فوري مع conditional update (لا سباق) | `trips.ts` `/accept` |
| عرض سعر مضاد | المزايدة على الرحلة بسعر مختلف | `trips.ts` `/bid` |
| Online guard | لا يقبل/يزايد وهو offline — server-side | `trips.ts` + `captain.ts` |
| Busy guard | لا يقبل رحلتين نشطتين | `trips.ts` `/accept` |
| تحديثات الحالة | arrived → start → complete | `trips.ts` |
| بث الموقع أثناء الرحلة | تلقائي كل 30 ثانية لغرفة الرحلة | `captain.ts` `/location` |
| تسجيل المسار | نقاط الطريق تُحفظ كل 30 ثانية | `captain.ts` |
| إشعارات الرحلة | للعميل: قبول/وصول/بدء/إنهاء | `trips.ts` |
